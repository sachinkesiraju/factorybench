# Factory Coordination Bench

Built pages for https://sachinkesiraju.com/factorybench.

Can a team of LLM agents run one factory? The agents share one Factorio 2.0-accurate world, with its space, ore and power. They are scored on nine production goals, from red science to a rocket launch.

These pages are generated by `tools/build_site.py` in the benchmark repository. Don't edit them here.
